# Gemini Live Agents (DevFest Vancouver 2026)

Eric Tech's talk: how to build voice AI agents with the Gemini Live API, and why Jarvis is cascaded. 24 slides, about 14 minutes plus Q&A.

- `Gemini Live Agents.pdf`: every slide, one per page. Opens anywhere.
- `index.html`: the live deck. Download this folder and open `index.html` in Chrome; `assets/` holds the fonts and images, so it works offline.

Keys in the HTML deck: `←` / `→` move, `N` speaker notes, `O` all slides, `T` theme, `F` fullscreen.
